### Модуль 1: Выбор технологии (`chapter1.bat`)
Модуль оценивает характеристики проекта (инфраструктура, скорость настройки пайплайнов, бюджет и размер команды из 5 Python-разработчиков) и вычисляет итоговую рекомендацию.

*Ключевые участки кода:*
* `chcp 65001 > nul` — переключает кодировку консоли на UTF-8 для корректного вывода кириллицы.
* `choice /c 123 /n` — считывает выбор пользователя без необходимости нажимать Enter.
* `set /a score_gitlab+=20` — начисляет баллы соответствующему кандидату в зависимости от ответа (`errorlevel`).
* Блок условий `if %score_jenkins% gtr ...` — определяет лидера по сумме баллов и сохраняет его имя в переменную `rec_tech`.

```bat
@echo off
chcp 65001 > nul
set score_gitlab=0
set score_jenkins=0
set score_circleci=0

echo === Модуль выбора CI/CD системы (Вариант 7) ===
echo.

echo Вопрос 1: Где планируется размещать инфраструктуру для сборки и деплоя?
echo 1. Облачный сервис без необходимости администрировать свои серверы
echo 2. В связке с репозиторием GitLab (облако или свой сервер с авто-раннерами)
echo 3. Полностью на собственных серверах (On-Premise) с тонкой настройкой
choice /c 123 /n
if errorlevel 3 set /a score_jenkins+=20
if errorlevel 2 set /a score_gitlab+=20
if errorlevel 1 set /a score_circleci+=20
echo.

echo Вопрос 2: Насколько критична скорость запуска и настройки пайплайнов?
echo 1. Максимально быстро: нужны готовые шаблоны (Orbs) для Python и Docker
echo 2. Быстро: декларативный YAML-файл прямо в корне репозитория
echo 3. Сроки позволяют потратить время на установку плагинов и написание Groovy-скриптов
choice /c 123 /n
if errorlevel 3 set /a score_jenkins+=15
if errorlevel 2 set /a score_gitlab+=15
if errorlevel 1 set /a score_circleci+=15
echo.

echo Вопрос 3: Каков бюджет и размер команды (5 Python-разработчиков)?
echo 1. Бюджет минимальный, нет выделенного DevOps-инженера, код уже в GitLab
echo 2. Бюджет нулевой на лицензии, но в команде есть специалист для поддержки сервера
echo 3. Есть бюджет на облачные минуты ради максимальной скорости сборки
choice /c 123 /n
if errorlevel 3 set /a score_circleci+=15
if errorlevel 2 set /a score_jenkins+=15
if errorlevel 1 set /a score_gitlab+=15
echo.

echo Итоговые баллы: GitLab CI = %score_gitlab%, Jenkins = %score_jenkins%, CircleCI = %score_circleci%

set rec_tech=GitLab CI
if %score_jenkins% gtr %score_gitlab% if %score_jenkins% geq %score_circleci% set rec_tech=Jenkins
if %score_circleci% gtr %score_gitlab% if %score_circleci% gtr %score_jenkins% set rec_tech=CircleCI

echo Рекомендация: %rec_tech%
echo.
pause
```

Модуль демонстрирует 3 фрагмента кода на Python, связанных со скриптами деплоя и миграций в CI/CD, и предлагает определить тип дефекта.

*Ключевые участки кода:*
* Метки `:right1` / `:wrong1` и команда `goto` — разделяют ветки начисления (`+10`) и списания (`-5`) очков.
* `set /a percentage=correct*100/total` — вычисляет процент точности ответов.
* Условия сравнения `if %percentage% geq 80` — присваивают уровень ревьюера (`Senior`, `Middle`, `Junior`) переменной `reviewer_level`.

```bat
@echo off
chcp 65001 > nul
set correct=0
set points=0
set total=3

echo === Модуль инспекции кода CI/CD (Вариант 7) ===
echo.

echo Фрагмент 1 (скрипт деплоя Python-приложения в GitLab CI):
echo 10: def deploy_service(env):
echo 11:     status = run_ansible_playbook(env)
echo 12:     return status
echo 13:     notify_slack("Deploy finished!")
echo.
echo Какой дефект здесь скрыт?
echo 1. Мёртвое присваивание
echo 2. Недостижимый код после return (уведомление в Slack не отправится)
echo 3. Неинициализированная переменная
choice /c 123 /n
if errorlevel 3 goto wrong1
if errorlevel 2 goto right1
if errorlevel 1 goto wrong1

:right1
echo Верно! Строка 13 после return никогда не выполнится. (+10 очков)
set /a correct+=1
set /a points+=10
goto frag2

:wrong1
echo Неверно. Правильный ответ: 2. (-5 очков)
set /a points-=5

:frag2
echo.
echo Фрагмент 2 (проверка времени сборки в Jenkins Pipeline):
echo 20: def check_build_timeout(duration_sec):
echo 21:     if duration_sec ^> 1800:
echo 22:         abort_pipeline()
echo 23:     return True
echo.
echo Какой дефект здесь скрыт?
echo 1. Магическое число (1800 секунд нужно вынести в константу MAX_BUILD_TIME)
echo 2. Утечка ресурса
echo 3. Неинициализированная переменная
choice /c 123 /n
if errorlevel 3 goto wrong2
if errorlevel 2 goto wrong2
if errorlevel 1 goto right2

:right2
echo Верно! Число 1800 вшито в код без пояснения, его нужно вынести в константу. (+10 очков)
set /a correct+=1
set /a points+=10
goto frag3

:wrong2
echo Неверно. Правильный ответ: 1. (-5 очков)
set /a points-=5

:frag3
echo.
echo Фрагмент 3 (запуск тестов и миграций БД в CircleCI):
echo 30: def run_migrations(db_url):
echo 31:     conn = connect_db(db_url)
echo 32:     conn.execute("ALTER TABLE users ADD COLUMN role TEXT;")
echo 33:     return "OK"
echo.
echo Какой дефект здесь скрыт?
echo 1. Мёртвое присваивание
echo 2. Неинициализированная переменная
echo 3. Отсутствие обработки ошибок и закрытия соединения (утечка ресурса)
choice /c 123 /n
if errorlevel 3 goto right3
if errorlevel 2 goto wrong3
if errorlevel 1 goto wrong3

:right3
echo Верно! Нет блока try/except/finally для перехвата ошибок миграции и закрытия conn. (+10 очков)
set /a correct+=1
set /a points+=10
goto report2

:wrong3
echo Неверно. Правильный ответ: 3. (-5 очков)
set /a points-=5

:report2
echo.
echo === Итоговый отчёт инспекции ===
echo Просмотрено фрагментов: %total%
echo Правильных ответов: %correct% из %total%
echo Набрано очков: %points%
set /a percentage=correct*100/total
echo Точность: %percentage%%%

set reviewer_level=Junior Reviewer
if %percentage% geq 80 set reviewer_level=Senior Reviewer
if %percentage% geq 50 if %percentage% lss 80 set reviewer_level=Middle Reviewer

echo Уровень ревьюера: %reviewer_level%
echo.
pause
```

Модуль реализует метод взвешенной суммы (WSM) для сравнения GitLab CI, Jenkins и CircleCI по трём критериям.

*Ключевые участки кода:*
* Проверка `if %total_weight% neq 100` — контролирует корректность ввода весов и возвращает пользователя к метке `:weights` при ошибке.
* `set /a score_gl=gl_1*w1+gl_2*w2+gl_3*w3` — рассчитывает взвешенную сумму баллов по формуле $S = \sum(W \times X)$.
* Символ экранирования `^|` — позволяет вывести псевдографическую таблицу матрицы решений в консоль.

```bat
@echo off
chcp 65001 > nul

:weights
echo === Модуль сравнительного анализа CI/CD систем (WSM) ===
echo.
echo Назначьте веса критериям (сумма должна быть равна 100):
set /p w1="Вес критерия 1 (Скорость настройки и деплоя): "
set /p w2="Вес критерия 2 (Простота поддержки для команды из 5 чел.): "
set /p w3="Вес критерия 3 (Стоимость владения / бесплатные лимиты): "

set /a total_weight=w1+w2+w3
if %total_weight% neq 100 (
    echo Ошибка: сумма весов равна %total_weight%, а должна быть 100! Попробуйте снова.
    echo.
    goto weights
)

echo.
echo Оцените альтернативы по шкале от 1 до 5:
echo --- GitLab CI ---
set /p gl_1="GitLab CI по критерию 1 (Скорость настройки): "
set /p gl_2="GitLab CI по критерию 2 (Простота поддержки): "
set /p gl_3="GitLab CI по критерию 3 (Стоимость владения): "

echo --- Jenkins ---
set /p jk_1="Jenkins по критерию 1 (Скорость настройки): "
set /p jk_2="Jenkins по критерию 2 (Простота поддержки): "
set /p jk_3="Jenkins по критерию 3 (Стоимость владения): "

echo --- CircleCI ---
set /p cc_1="CircleCI по критерию 1 (Скорость настройки): "
set /p cc_2="CircleCI по критерию 2 (Простота поддержки): "
set /p cc_3="CircleCI по критерию 3 (Стоимость владения): "

set /a score_gl=gl_1*w1+gl_2*w2+gl_3*w3
set /a score_jk=jk_1*w1+jk_2*w2+jk_3*w3
set /a score_cc=cc_1*w1+cc_2*w2+cc_3*w3

echo.
echo === Матрица решений ===
echo Критерий              ^| Вес ^| GitLab CI ^| Jenkins ^| CircleCI
echo --------------------------------------------------------------
echo Скорость деплоя       ^| %w1%  ^| %gl_1%         ^| %jk_1%       ^| %cc_1%
echo Простота поддержки    ^| %w2%  ^| %gl_2%         ^| %jk_2%       ^| %cc_2%
echo Стоимость владения    ^| %w3%  ^| %gl_3%         ^| %jk_3%       ^| %cc_3%
echo --------------------------------------------------------------
echo ИТОГО                 ^| 100 ^| %score_gl%       ^| %score_jk%     ^| %score_cc%
echo.

set wsm_winner=GitLab CI
if %score_jk% gtr %score_gl% if %score_jk% geq %score_cc% set wsm_winner=Jenkins
if %score_cc% gtr %score_gl% if %score_cc% gtr %score_jk% set wsm_winner=CircleCI

echo Победитель сравнительного анализа: %wsm_winner%
echo.
pause
```

Объединяет все три модуля через команду `call` и записывает сводный отчёт в файл `report.txt`.

*Ключевые участки кода:*
* `call chapter1.bat` — запускает дочерний скрипт в том же окружении, сохраняя значения переменных `rec_tech`, `reviewer_level` и `wsm_winner`.
* Конструкция `( echo ... ) > report.txt` — перенаправляет вывод итогового отчёта в текстовый файл в текущей директории.

```bat
@echo off
chcp 65001 > nul

:menu
cls
echo
echo   СИСТЕМА МОДЕЛИРОВАНИЯ ПРОЦЕССОВ РАЗРАБОТКИ ПО
echo.
echo 1. Модуль выбора технологий (chapter1.bat)
echo 2. Модуль инспекции кода (chapter2.bat)
echo 3. Модуль сравнительного анализа (chapter3.bat)
echo 4. Запустить все модули последовательно
echo 5. Выход
echo.
set /p choice="Ваш выбор (1-5): "
if "%choice%"=="1" (
cls
call chapter1.bat
)
if "%choice%"=="2" (
cls
call chapter2.bat
)
if "%choice%"=="3" (
cls
call chapter3.bat
)
if "%choice%"=="4" (
cls
call chapter1.bat
cls
call chapter2.bat
cls
call chapter3.bat
cls
echo ====================================================
echo ИТОГОВЫЙ ОТЧЁТ СИСТЕМЫ
echo ====================================================
echo.
echo Модуль 1 (Выбор технологии): Рекомендован %rec_tech%
echo Модуль 2 (Инспекция кода): Уровень - %reviewer_level% (Точность: %percentage%%%)
echo Модуль 3 (Анализ WSM): Победитель - %wsm_winner%
echo.
(
echo ====================================================
echo ИТОГОВЫЙ ОТЧЁТ СИСТЕМЫ (Вариант 7)
echo ====================================================
echo Дата и время формирования: %DATE% %TIME%
echo.
echo 1. Рекомендация по выбору CI/CD системы: %rec_tech%
echo 2. Результат код-ревью: %reviewer_level% (Точность: %percentage%%%, Очки: %points%)
echo 3. Победитель сравнительного анализа (WSM): %wsm_winner%
) > report.txt
echo Отчёт успешно сохранён в файл report.txt
echo.
pause
)
if "%choice%"=="5" exit
goto menu
```

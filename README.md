
##  Техническое описание логики

### 1. Категории базовово ПО (чо выбрали и почему)
Мы собрали самый нужный набор — вещи, без которых обычный работяга за компом взвыл бы в первый же день:

| Категория ПО | Ключевые слова поиска | Зачем это надо? |
| :--- | :--- | :--- |
| **Офисный пакэт** | `Office`, `LibreOffice`, `МойОфис` | Без него никакой файлик не нарисовать и цыферки не посчитать. |
| **Архиватары** | `7-Zip`, `WinRAR`, `WinZip` | Из почьты постоянно прилетают сжатые папки, надо их открывать. |
| **Просмотр PDF** | `Acrobat`, `Foxit`, `SumatraPDF` | Всякие важные доки и акты обычно весят в ПДФ формате. |
| **Браузеры** | `Chrome`, `Firefox`, `Yandex` | Если сторонних не завезли, пускай работает встроенный Edge. |
| **Антивируска** | `Kaspersky`, `ESET`, `Dr.Web`, `Defender` | Чтоб никакой вирусняк не пролез, палим состояние защиты. |

### 2. Признаки излишнево ПО (как ловили левые проги)
Чтобы рабочее место не превратилось в клуб для геймеров или рассадник заразы, скрипт вылавливает софт по меткам:
*  **Игрульки и лаунчеры:** Палим по меткам `Steam`, `Epic Games`, `GOG`, `Origin`, `game`, `gaming`. Если кто-то катает в рабочее время — мы это заметим.
*  **Качалки и торренты:** Ищем фразы `torrent`, `uTorrent`, `BitTorrent`, `qBittorrent`. Они намертво забивают сеть и кушают весь трафик.
*  **Болталки и месенджеры:** Ловим слова `Discord`, `Telegram`, `WhatsApp`, `Viber`. Это чтобы админы проверили, можно ли вообще тут сидеть.

## Тестирование работоспособности
Проверяли, как пашет логика, дедовскими, но железными методами:
1. **Тест на голом ПК:** Запускали на пустой винде — скрипт ожидаемо выдал кучу уведомлений `[ВНИМАНИЕ]` по всем статьям.
2. **Тест на детекцию:** Поставили ради прикола `7-Zip` и `Telegram`, запустили — скрипт четко написал `Нашолся 7-Zip` в нужных и спалил `Telegram` в левых.
3. **Тест на прочность:** Намеренно затирали доступ к папкам темпа — скрипт нормально ругался и падал с ошыбкой, не уходя в бесконечный цикл.

## Ограничения полученново решения
У нашей софтины есть несколько косяков, про которые стоит помнить перед сдачей:

<details>

* **Видит только через инсталлятор:** Чек идет сугубо по записям `Uninstall`. Если юзер притащил *Portable-версию* на флешке, которая запускается без установки, скрипт её прохлопает.
* **Зависит от PowerShell и WMIC:** Если злые админы залочили PowerShell или вырубили WMIC службу, то по процу, диску Ц и памети выскочит статус `[ОШЫБКА]`.
* **Прямое совпадение букв:** Поиск идет строго по буквам. Если какая-то левая софтина или игра названа вообще без использования слова `game`, скрипт её пропустит.

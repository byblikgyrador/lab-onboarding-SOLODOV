1.  `movl $0, -4(%rbp)` — инициализация аккумулятора (суммы) значением `0`.
2.  `movl $1, -8(%rbp)` — инициализация счетчика цикла значением `1`.
3.  `jmp .L2` — безусловный переход к проверке условия цикла (оптимизация компилятора для циклов с предусловием).
4.  Блок **.L3** (Тело цикла):
    *   `movl -8(%rbp), %eax` — загрузка текущего значения счетчика в регистр `%eax`.
    *   `addl %eax, -4(%rbp)` — прибавление счетчика к аккумулятору (`сумма += счетчик`).
    *   `addl $1, -8(%rbp)` — инкремент счетчика на 1 (`счетчик += 1`).
5.  Блок **.L2** (Условие цикла):
    *   `cmpl $10, -8(%rbp)` — сравнение значения счетчика с числом `10`.
    *   `jle .L3` — если счетчик `<= 10`, переход на новый виток цикла в блок `.L3`.
6.  `movl -4(%rbp), %eax` — после выхода из цикла итоговая сумма копируется в регистр возврата `%eax`. Результат вычислений равен **55**.

### Эквивалентный код на Python

Аналог на языке Python с сохранением структуры оригинального цикла (`while`):

```python
def calculate_sum():
    total_sum = 0  # -4(%rbp)
    counter = 1    # -8(%rbp)
    
    while counter <= 10:  # cmpl $10 + jle .L3
        total_sum += counter  # addl %eax, -4(%rbp)
        counter += 1          # addl $1, -8(%rbp)
        
    return total_sum  # movl -4(%rbp), %eax
```

```python
def calculate_sum_idiomatic():
    return sum(range(1, 11))
```
